# Решение по кейсу №2 (Reciper)

## Выбранное задание

- Кейс: `tasks/task-02-yandex-shad.md`
- Название: **Reciper — мобильный AI-ассистент питания, рецептов и готовки**

## Цель MVP

Сделать мобильное решение, которое:

- помогает формировать персональный план питания;
- умеет подбирать/генерировать рецепты;
- поддерживает сценарий сканирования продуктов;
- дает режим готовки с пошаговым UX;
- хранит пользовательские данные локально и работает с backend для AI-задач.

## Архитектура решения

### Клиент (`src/client/`)

- Flutter-приложение с разделением по слоям: `app/core/data/domain/module/services/widgets`.
- Управление состоянием — BLoC.
- Локальное хранение — Drift + SQLite.
- Сетевое взаимодействие через `dio`.

### Backend (`src/backend/`)

- FastAPI-приложение (статeless AI-orchestrator).
- Ключевые функции: генерация плана, замена блюда, подбор/генерация рецептов, health endpoint.
- Конфигурация через `.env` (`pydantic-settings`).
- Контейнеризация через Docker, запуск через `docker compose`.

## Что уже закрывает критерии кейса

- **Архитектура и код**: 
  - Flutter-приложение с чистой архитектурой (BLoC, Drift/SQLite)
  - FastAPI backend в Docker-контейнере, Swagger-документация
  - Асинхронная работа — UI не зависает при обращении к AI
  - Логика отделена от UI через репозитории

- **Легкий deploy**: 
  - Единый `docker-compose.yml` — запуск backend одной командой
  - Пошаговый `DEPLOY.md` с инструкциями
  - Готовая APK для быстрого тестирования

- **Функциональность (MVP-контур)**: 
  - Генерация персонального плана питания (учёт целей, аллергий, предпочтений)
  - AI-распознавание продуктов по фото, подбор рецептов
  - Продвинутый режим готовки: пошаговый UX, озвучка, таймеры
  - Редактирование планов, "Избранное", списки покупок
  - Графики веса, статистика калорий, push-уведомления, тёмная/светлая темы

## Как проверять решение

Использовать только инструкции из `DEPLOY.md`:

1. подготовить `src/backend/.env`;
2. поднять проект через `docker compose up -d --build`;
3. проверить `GET /api/v1/health` и `/docs`;
4. запустить `pytest` внутри контейнера.

## Ограничения MVP

- AI-качество зависит от внешнего LLM API и корректного API-ключа.
- Для мобильного клиента серверный URL должен быть передан через `--dart-define=API_BASE_URL=...` при сборке release APK.
